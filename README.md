# TurboCraft

Собственный мод оптимизации для Minecraft (Fabric), версии **1.21.11** и **26.3**.

## Что делает

1. **Отсечение дальних сущностей при отрисовке.** Мобы, предметы, стойки и т.п. дальше
   `entityRenderDistance` блоков не рисуются. Игроки, светящиеся сущности и крупные боссы видны всегда.
2. **Экономия ИИ дальних мобов.** Мобы дальше `farMobDistance` блоков от всех игроков «думают»
   (выбор целей, поиск пути) раз в `farMobAiInterval` тиков вместо каждого тика. Физика работает
   как обычно, а мобы, которые кого-то атакуют, не замедляются. Работает и в одиночной игре, и на сервере.
3. **Экономия столкновений дальних мобов.** Толкание мобов друг о друга (фермы, загоны с жителями) —
   одна из самых дорогих операций сервера. Вдали от игроков оно считается раз в `farMobAiInterval` тиков.
4. **Отсечение дальних частиц.** Частицы дальше `particleDistance` блоков от игрока не создаются вовсе.

## Установка

1. Установите Fabric Loader для своей версии игры.
2. Скачайте `turbocraft-1.0.0+<версия>.jar` из раздела Releases и положите в `.minecraft/mods`.
   Fabric API не нужен.

## Настройки

После первого запуска появится `.minecraft/config/turbocraft.json`:

```json
{
  "entityRenderDistance": 64,
  "farMobDistance": 48,
  "farMobAiInterval": 4,
  "particleDistance": 24
}
```

`0` в любом из расстояний выключает соответствующую функцию.

## Сборка

`cd mc-1.21.11 && gradle build` (или `mc-26.3`). Нужны Gradle 9 и JDK 25. Готовый файл появится в `build/libs`.
Общий код лежит в `common/`.
